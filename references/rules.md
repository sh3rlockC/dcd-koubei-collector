# 懂车帝车型口碑采集规则参考

## 1. 输入规则

优先输入：
- 完整懂车帝口碑页 URL
- 车型口碑列表页 URL + 页码范围
- 自然语言描述

## 2. 文件命名规则

默认命名：
- `DCD口碑_车型_日期.xlsx`

例如：
- `DCD口碑_小米SU7_2026-03-27.xlsx`

## 3. 导出规则

默认输出 1 个 sheet：
- `口碑明细`

## 4. 正式版字段

1. 用户名
2. 用户标签
3. 评价车型
4. 懂车分
5. 发布时间
6. 用户评分
7. 续航
8. 购车时间
9. 裸车价
10. 购车地
11. 评价全文
12. 来源链接
13. 抓取页码

## 5. 校验规则

每条记录至少包含：
- 评价车型
- 发布时间
- 评价全文
- 来源链接

缺任一项时：
- 标记异常
- 不直接写入正式结果

## 6. 当前已知差异

- 不再区分“最满意 / 最不满意”
- 不需要双维度对齐
- 直接抓取评价全文
- 详情页可能比列表页更完整，需抽样验证
